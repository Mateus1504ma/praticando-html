Tecnologia

HTML

O HTML (Linguagem de Marcação de Hipertexto) é a linguagem padrão utilizada para criar e estruturar a base de páginas na internet.

CSS

O CSS (Cascading Style Sheets ou Folhas de Estilo em Cascata) é uma linguagem declarativa usada para definir a aparência e o design de páginas web.

Javascript

O JavaScript (frequentemente chamado de JS) é uma linguagem de programação interpretada, de alto nível e com tipagem dinâmica.
